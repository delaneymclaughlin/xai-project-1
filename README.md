# Algorithmic Design Features

Engagement-based ranking and the limits of reactive regulation. A one-page
scrolling site for Explainable AI (Duke University, Fall 2026) by Delaney
McLaughlin.

Astro 7 (static output) + Tailwind CSS 4, deployed as static assets on
Cloudflare Workers. No UI framework; interactives are vanilla TypeScript.

## Commands

Requires Node >= 22.22.

| Command | Action |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Dev server at `localhost:4321` (agents: `npx astro dev --background`) |
| `npm run build` | Build to `./dist/` (first build downloads fonts, so it needs network) |
| `npm run preview` | Serve the build locally |
| `npm run check` | Type-check with `astro check` |
| `npm run deploy:dry` | Build, then `wrangler deploy --dry-run` |
| `npm run deploy` | Build, then `wrangler deploy` (needs `wrangler login` or `CLOUDFLARE_API_TOKEN`) |

## Layout

- `content/site.json`: all page copy, ledger and sources (fact-checked). `content/claims.verified.json`: fact-check notes.
- `src/data/sim.json`, `src/data/demo.json`: simulation tokens and precomputed outputs (regenerated by the simulation step).
- `src/lib/content.ts`: the only module that reads the JSON. Resolves `{{sim.*}}` tokens; a missing token fails the build.
- `src/components/`: shared primitives (`Section`, `Claim`, `Cite`, `Simulated`, `Para`, `Takeaway`, `ui/Chip`, `ui/Toggle`).
- `src/components/sections/`: one file (or folder) per page section. `src/scripts/`: one script per interactive.
- `docs/design.md`: design spec. `docs/tech-brief.md`: stack notes.
